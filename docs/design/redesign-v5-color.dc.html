리디자인 v5 — 색·서체 방향

노란색을 빼고 유치원 톤을 걷어낸 세 방향을 같은 화면에 그렸습니다. 서체는 셋 다 Pretendard로 통일해서 색만 비교되게 했습니다(Jua는 굵기가 하나뿐이라 크기·자간으로 위계를 만들어야 했는데, 굵기가 생기면서 그 우회가 사라집니다).
v4에서 이어갑니다 — 하단 고정 CTA · 44px 탭 타깃 · 이름 13px 이상 · 사진 위 글씨 금지 · 균일 그리드는 그대로 지켰습니다.

함께 걷어낸 것: 치즈 도트 텍스처(사진 빈 자리 → 선 아이콘) · 🧀 토스트 · 🐭 쥐 진행률 · 큰 치즈 심볼 반복. 색만 바꾸고 이것들을 두면 인상의 절반이 그대로 남습니다.

0. 세 방향이 공통으로 바꾸는 것

방향 선택과 무관하게 아래 셋은 같습니다. 그래야 비교가 색 얘기로만 남습니다.

① 배경과 카드의 관계를 뒤집습니다

지금은 크림 배경(#FFFDF5) 위에 흰 카드라 명도차가 1.02:1 — 사실상 같은 색입니다. 그래서 경계를 전부 테두리·그림자가 떠맡았고 팔레트에 없는 임의 색(#D8CFBB·#C9C2B4)이 생겼습니다. 이제 배경을 연회색으로 내리고 카드를 순백으로 올립니다(명도차 1.16:1 — 8배). 카드가 스스로 떠올라서 그림자가 필요 없어집니다.

② 상태 배지: 색 5개 → 색 3개 + 채움 무게 4단

노랑을 빼면 5개 상태를 색만으로 가를 수 없습니다. 진행 단계를 채움 무게로 인코딩합니다 — 아웃라인(NEW) → 포인트 아웃라인(분류중) → 틴트(검수 대기) → 솔리드(공개 준비 = 할 일) → 성공 틴트(공개 완료). 지금 색이 정해지지 않은 채 남아 있던 '검수중'도 여기서 자리를 얻습니다.

③ 버튼 글자색 규칙이 정반대로 뒤집힙니다

지금 규칙은 "옐로우 위 흰 글자 금지"(흰 글자 대비가 1.54라서)입니다. 세 방향 모두 주 버튼이 어두운 면이 되므로 전부 흰 글자가 되고, 오히려 어두운 글자가 금지됩니다.

1. 홈 — 사진첩 목록

상태 배지 5종이 한 화면에 나오도록 구성했습니다. 카드 경계·배지·버튼을 함께 보세요.

2. 사진첩 안 — 인물 앨범

AI가 나눈 인물 앨범 그리드. 점선 테두리(미검토)가 화면을 덮던 문제를 채움 대비로 바꿨습니다.

3. 사진 격자

현행은 간격 10px·모서리 12px이라 "카드 모음"으로 읽힙니다. 여기선 간격 3px·모서리 2px — 사진 앱 문법입니다. 사진이 화면을 채우면 UI 색이 얼마나 물러서는지가 여기서 가장 잘 보입니다.

4. 팔레트와 대비

5. 로고는 어떻게 되나

"UI는 무채색인데 로고만 노랑"은 성립합니다 — 조건이 있습니다. 무채색 화면에서 유일한 채도는 시그니처가 되지만, 여러 번 반복되면 얼룩이 됩니다. 지금은 빈 상태 화면마다 76px 치즈가 박히고(빈 모임·빈 이벤트·빈 앨범…), 모임 카드마다 40px 치즈가 붙습니다. 마크가 허용되는 자리는 헤더와 랜딩 둘뿐이어야 합니다.

⚠ 노랑은 어차피 화면에서 완전히 못 없앱니다 — 카카오 로그인 버튼이 브랜드 고정색(#FEE500)이고, 랜딩에서 치즈 마크 바로 아래 전폭으로 깔립니다. 그래서 랜딩에서는 마크를 잉크로 렌더해 노랑을 카카오 버튼 하나로 몰아주는 쪽을 권합니다(위 오른쪽 시안).

6. 정리

A 무채색 — 사진 색을 가장 안 건드립니다(캔버스 채도 4%). 파란 링크는 전 연령이 이미 학습한 신호라 "전 연령 무리 없음" 기준에서 가장 안전합니다. 주 버튼 대비 16.9:1로 여유가 가장 큽니다.
B 웜 톤다운 — 로고와 가장 편안하지만, 요구("노랑 빼기·유치원 탈피")를 절반만 만족합니다. 채도만 낮춘 웜톤은 "노랑을 뺐다"가 아니라 "흐렸다"로 읽힐 위험이 있고, 카드가 순백이 아니라 흰색을 쓴 자리 40곳을 전부 바꿔야 해 비용도 가장 큽니다.
C 딥그린 — 마크가 가장 잘 삽니다(딥그린+골드는 고전 보색 페어). 다만 초록이 여행·야외 사진의 지배 색과 같은 계열이라 사진 위 UI 경계가 흐려질 수 있습니다.

되돌리기 비용이 판단을 갈랐습니다. A와 C는 회색 사다리가 사실상 같아서 A로 간 뒤 주색 토큰 두 개만 딥그린으로 바꾸면 C가 됩니다. 반대로 B는 웜 계열 전체가 묶여 되돌리기 어렵습니다. A를 권합니다.
