# 관리자 이벤트 설문 연결

사용자 승인 범위: 앱 수정 없이 기존 이벤트 팝업에서 웹 모임 선택 후 구글폼 자동 입력.
기존 이벤트 팝업 관리(CHMO-928)의 후속 변경이다. Jira 도구는 미연결 상태다.

## 화면과 계약

`/survey?lang=ko#token=...`는 로그인 가드 밖의 외부 페이지다.
임시 토큰은 fragment에서만 읽고 메모리로 전달한다. localStorage·로그인 세션에 저장하지 않는다.
서버에 `X-Survey-Token`을 보내 닉네임과 ACTIVE 모임 목록을 받는다.
모임을 고르고 `설문으로 이동`을 누르면 서버가 최신 값과 멤버십을 확인해 반환한
이번 Google Forms HTTPS 주소로 이동한다. 외부 주소는 이번 폼 경로만 허용한다.

- 초기 로딩, 모임 없음, 만료/잘못된 주소, 네트워크 실패, 이동 중 상태를 구분한다.
- 오류는 같은 페이지에서 재시도하거나 앱의 이벤트 안내에서 다시 시작하도록 설명한다.
- ko/en/ja 외부 페이지 언어 규칙과 치즈모아 브랜드·버튼을 재사용한다.
- 이름·토큰·URL은 분석에 보내지 않는다. 이 페이지는 분석 SDK·푸시 동기화를 부팅하지 않는다.
- 배포 헤더는 `Referrer-Policy: no-referrer`, `Cache-Control: no-store`다.
- 관리자 등록 폼의 API·입력 방식은 바꾸지 않고 이번 폼의 자동 입력 안내만 추가한다.

API: `GET /popup-surveys/context`, `POST /popup-surveys/link` (`{groupId}`),
기존 봉투·`X-Survey-Token` 인증. 인증 실패는 `SURVEY401`, 종료된 이벤트는 `SURVEY404`,
모임 접근 불가는 `SPACE403`이다. 일반 회원 JWT를 붙이거나 재발급하지 않는다.

## 배포 순서

웹을 먼저 배포하고 서버를 뒤에 배포한다. 서버 기본 연결 주소는
`https://app.cheese-moa.com/survey`, 스테이징은 `POPUP_SURVEY_WEB_URL`로 분리한다.
그 뒤 관리자는 기존 이벤트의 링크 입력란에 해당 구글폼 원본 주소를 등록한다.
관리자 미리보기는 공용 원본 링크이므로 사용자별 입력은 실제 앱 팝업 경로로 확인한다.

## 검증 결과

타입 검사·lint·Vitest 536개·운영 빌드 통과. 로컬 브라우저에서 모임 선택,
연결 오류·재시도, 잘못된 주소, 언어 전환을 합성 데이터로 확인했다.
운영 배포와 실제 앱에서 Google Forms 착지 확인은 아직 수행하지 않았다.
